CSS Box Model Exploration

CONTENT

Default Box Model: Width and height apply to content only. Padding and border add to total size.

CONTENT

box-sizing: border-box; Width and height include padding and border. Total size stays fixed.

Box Model Layers

  • Content: The actual content (text, images, etc.)
  • Padding: Space between content and border
  • Border: Line around padding and content
  • Margin: Space outside the border
